# WEMADEIT

אפליקציה אישית לללי ועמרי: להזיז דברים שקל לדחות, מהשבוע ועד סוף 2026.

## איך זה עובד
1. **שאלון**: כל אחד עונה על שאלות בכל תחום (בריאות, שגרה, עבודה, שיווק, קידום פרויקטים, כסף ותפעול העסק, אחר).
2. **תוכנית**: האפליקציה מכינה הודעה ל-Claude. בונים איתו תוכנית, ומדביקים אותה בחזרה.
3. **תכנון שבועי (מוצ"ש)**: בוחרים יום עבודה משותף, Claude משבץ את המשימות לפי היומן ומכניס אותן ליומן, ומדביקים את השיבוץ בחזרה.

המידע נשמר רק בטלפון של כל אחד. יש כפתור גיבוי במסך "אני".

## קבצים
- `index.html`, `styles.css`, `app.js`: האפליקציה עצמה
- `questions.js`: התחומים והשאלון (אפשר לערוך כאן שאלות)
- `sw.js`, `manifest.webmanifest`, `icons/`: מה שמאפשר להתקין למסך הבית
- `design/`: טיוטות העיצוב
